放置目录教程

  1. 打开 SD 卡根目录。
  2. 进入 atmosphere → exefs_patches。
  3. 新建下面这个文件夹，不要放进 es_patches、nfim_ctest、nim_ctest 或 SaltyNX_Fixes 里。
  4. 把下载出来的 .ips 文件放进去。
  5. 完全退出游戏后重新进；不生效就重启一次 Switch/大气层。

          
注意：游戏版本和 Build ID 必须匹配。比如 1.1.0 的补丁通常不能给 1.1.1、1.2.0、1.2.1 用。

        

      

    


    

      
常见错误

      
不要放到金手指目录，也不要套一层 exefs 子目录。下面这种一般是错的：

      
atmosphere\contents\0100F2C0115B6000\cheats\...
atmosphere\exefs_patches\60fps_patch\exefs\xxxx.ips
Switch\金手指文件夹\0100F2C0115B6000\60fps_patch\exefs

      
Atmosphere 读取 exefs IPS 补丁时，目标结构应是：

      
SD Card\atmosphere\exefs_patches\补丁文件夹名\BuildID.ips
